# Security and contact

PrivaPace is an unaudited Arc Testnet development release. Reports are welcome.

- **Security issues:** use GitHub's private vulnerability reporting on this
  repository ("Security" tab → "Report a vulnerability"). Please do not open a
  public issue for a vulnerability.
- **Operator problems, questions and checkpoint mismatches:** open a GitHub issue.
- **Official contracts:** only the addresses in [contracts.json](contracts.json),
  also published at <https://privapace.xyz/contracts.json>. Anything else claiming
  to be PrivaPace is not.

Never test against other people's funds or accounts.
